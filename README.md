# skill-sets.md directory feedback

Report a problem with a skill listed on [skill-sets.md](https://skill-sets.md): wrong or outdated details, broken links, or a skill that looks unsafe or has been removed.

[Open an issue](https://github.com/skill-sets/directory-feedback/issues/new/choose) and include the skill's page URL.

Issues here appear on the [skill-sets project board](https://github.com/orgs/skill-sets/projects/1).
